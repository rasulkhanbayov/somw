Windows certify consistency, not accuracy.

A restart from generated states removes only 20% of the error; one from the true start removes 94%. So repair needs a simulated state.

Phases 4b, 4c, 4e, 4g, 4g-v2, 4h; all pre-registered and kept as negative results

The second attempt is a Goodhart effect: optimising the generation against the window defect lowered the defect on held-out windows while the true error nearly doubled. Lesson recorded in the plan: use the defect as a certificate, never as an objective. The working repair (Result 3) follows directly from the last row's diagnosis: early restarts lost the stress state, and late restarts started from positions that had drifted although every earlier window passed.
